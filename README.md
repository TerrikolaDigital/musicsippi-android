# Musicsippi para Android

Solo descargas: cada versión está en **Releases** (APK + `version.json`). Sin código fuente ni datos personales.

- Instalar: descarga el último `.apk` desde Releases y ábrelo en Android.
- Actualizar: la app avisa sola, o usa Obtainium con este repositorio.

Contacto: terrikoladigital@gmail.com · @terrikoladigital

_Musicsippi no aloja música. Las canciones pertenecen a sus autores y se reproducen desde servicios de terceros. Uso personal, sin fines comerciales._
